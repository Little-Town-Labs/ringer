# Dispatch record

Manifests, check scripts and prompts used to build and review this feature with Ringer
(waves 1-3, the T009 review, and the T010 fix wave). They are kept as the audit trail of
how each task was specified and verified. They are historical: several reference the
draft assets and the one-off backfill script that were retired after the production push,
and they contain machine-specific absolute paths, so they are not meant to be re-run.
